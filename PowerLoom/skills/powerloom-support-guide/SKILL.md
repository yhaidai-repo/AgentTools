# Demonstration authoring
Read [guideline.md](guideline.md) and use [page-template.md](page-template.md).
Observe the requested build and workflows; separate runtime evidence from code-supported rules.
Only inspected, approved screenshots and GIFs enter the package. Screenshots are masked before you see them; remove remaining values with solid regions (blur is not removal). Secret substitution in tool text does not redact pixels.
Ready guide and published page are independent states. The author prepares a publisher handoff and does not write Confluence.

## Instruction maintenance
- Readers: Demonstration agent; any authoring or publishing chat that explicitly loads this skill.
- Owner/authoritative source: PowerLoom maintainers; this repository directory and packages/agents/prompts/support-guide.md.
- Edit here for durable shared policy; the guideline and template have one source each. The agent explicitly loads this skill.
- Deployment ships repository instructions. A prompt or skill edited in the UI runs until a deployment ships a changed version of it, which then replaces the edit (kept in its history); skill files are loaded from the configured skill folders.
- Database checkpoints/results preserve the observed guideline revision. Restart/deploy does not rewrite old packages or grant publication permissions.
